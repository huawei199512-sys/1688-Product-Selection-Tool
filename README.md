# 1688 Product Sourcing Tool

Find similar products on 1688 using an image or keyword.

A free, open-source product research tool for dropshippers,
ecommerce sellers, sourcing agents and developers.

## What can it do?

- 🔍 Search 1688 products by keyword
- 🖼️ Search products by image
- 📦 View product details
- 💰 Check prices and MOQ
- 🎨 Browse SKUs and product images
- 🤖 Ask AI questions about products
- 🌍 English / Chinese interface
- 🔓 Open source
